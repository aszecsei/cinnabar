# Scenes

Scenes are `.scene` text files (see [Editor](../../editor/document-and-scenes.md#scenes)). `just scenes` runs `cook scenes --cache build/<target>/content --config dev|release --root game=<content root>`. The cooker cannot lay out native components, because their types exist only in the game DLL, so it checks only the file: its syntax, and that the scene IDs and the script GUIDs that it names exist. A missing one is a warning. A scene with an error keeps its old blob. The cache key covers the cooker version, the configuration, the source path, the source and the `.meta` file.

The same pass cooks `.prefab` files, scenes with one root that other scenes instantiate, first, since a scene's cook expands the instances in it with `asset_format.scene_expand`: both kinds cook to flat scene blobs, a prefab's under the `Prefab` kind, so the loader never sees an instance. A scene's key also covers the source of every prefab that it reaches, so saving a prefab cooks the scenes that use it again, and its dependencies name the prefabs that it instantiates. A prefab without exactly one root, a cycle of prefabs, a nesting more than eight deep and an instance of an asset that is not a prefab are errors; a missing prefab and an override whose entity is gone are warnings. See [Prefabs](../../editor/prefabs.md#cooking).
